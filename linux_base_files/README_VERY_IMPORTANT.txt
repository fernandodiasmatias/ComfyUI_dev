ComfyUI Linux Portable (CPU only)

Requirements: Linux x86_64 with glibc 2.28 or newer (Rocky Linux 8 / RHEL 8 or newer).

To run ComfyUI:      ./run_cpu.sh
Then open:           http://127.0.0.1:8188

To update ComfyUI:   ./update/update_comfyui.sh

Put your models in ComfyUI/models/ (checkpoints, loras, vae, ...).

If run_cpu.sh is not executable after extracting, run: chmod +x run_cpu.sh update/*.sh
